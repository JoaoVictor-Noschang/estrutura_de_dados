## Sobre a disciplina

Este repositório reúne os materiais utilizados na disciplina de **Estrutura de Dados**, com conteúdos, exemplos de código em **C**, exercícios e atividades práticas.

O objetivo é centralizar os materiais da disciplina em um único local, facilitando o acesso e acompanhamento das aulas pelos alunos.

> **Como utilizar este repositório?**
> Escolha uma aula ou atividade abaixo e clique no botão correspondente para acessar diretamente o conteúdo.

---
</br>

# Organização do repositório

A estrutura do repositório segue uma organização simples para facilitar a localização dos materiais:

```text
estrutura-de-dados/
│
├── aulas/
│   ├── aula-01/
│   ├── aula-02/
│   ├── aula-03/
│   └── ...
│
├── atividades/
│   ├── atividade-01/
│   ├── atividade-02/
│   ├── atividade-03/
│   └── ...
│
├── README.md
└── ...
```

Cada pasta de aula ou atividade pode conter arquivos `.c`, exemplos, exercícios, PDFs ou outros materiais relacionados ao conteúdo.

# Linguagem utilizada

As implementações da disciplina são desenvolvidas principalmente em C com a IDE CLion.

[![My Skills](https://skillicons.dev/icons?i=c,cmake,clion)](https://skillicons.dev)

Os códigos podem ser compilados utilizando compiladores como **GCC**, **Clang** ou ambientes de desenvolvimento compatíveis com a linguagem C (CLion - JetBrains).

# Como acessar uma aula ou atividade

Para acessar um conteúdo, basta:

1. Localizar a aula ou atividade desejada neste README.
2. Clicar no botão **“Acessar”**.
3. Na página aberta, consultar os arquivos e materiais disponíveis.
4. Para visualizar um arquivo de código, clique sobre ele no GitHub.

> Não é necessário baixar o repositório para apenas consultar os materiais.
